# HttpServer
## Overview
HttpServer is a lightweight and efficient HTTP server written in Python. It is designed to handle HTTP requests and serve static files with minimal configuration.

## Features
- Simple and easy to use
- Lightweight and fast
- Supports GET and POST requests
- Serves static files
- Customizable request handlers

## Installation
To install HttpServer, clone the repository and install the required dependencies:
```bash
git clone https://github.com/adarsh/HttpServer.git
cd HttpServer
```

## Usage
To start the server, run the following command:
```bash
python server.py
```
By default, the server will start on `http://localhost:8080`. You can customize the port and other settings in the `config.py` file.
